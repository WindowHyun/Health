# 남은 작업

다른 운동 앱(Strong, Hevy, Nike Run Club, Strava, Garmin 등)과 비교해
빠져 있던 것을 모으고, **개인용 앱에 필요 없는 것을 먼저 덜어낸 뒤**
남은 것에 우선순위를 매긴 목록입니다.

기준은 두 가지입니다.

1. **기록을 잃을 수 있는가** — 잃으면 되돌릴 수 없으므로 가장 먼저 합니다.
2. **운동 중 조작을 줄이는가** — 이 앱의 가장 중요한 UX 원칙입니다.

---

## 제외 — 개인 앱에 필요 없음

처음부터 요구사항에서 빠져 있거나, 혼자 쓰는 앱에서는 값을 못 하는 기능입니다.

| 항목 | 이유 |
| --- | --- |
| 로그인 · 회원가입 · 계정 동기화 | 서버를 쓰지 않습니다. 기기 간 이동은 백업 파일로 합니다 |
| 친구 · 팔로우 · 피드 · 클럽 | 혼자 쓰는 앱입니다 |
| 랭킹 · 세그먼트 경쟁 · 챌린지 | 위와 같습니다 |
| 결제 · 구독 · 광고 | 상업용이 아닙니다 |
| 운동 영상 · 자세 가이드 | 유지 비용(영상 제작·저작권)이 개인 앱에 맞지 않습니다 |
| AI 코칭 · 자동 프로그램 생성 | 서버나 외부 API 가 필요합니다 |
| 웨어러블 앱(워치 전용 화면) | 별도 앱을 하나 더 만드는 일입니다. 심박은 Health Connect 로 받습니다 |
| 소셜 공유 카드 만들기 | 공유할 상대가 없습니다. CSV 내보내기로 대신합니다 |

## 완료 (v0.4.0)

| 순위 | 항목 | 왜 필요했나 |
| --- | --- | --- |
| P0-1 | 백업 / 복원 · CSV 내보내기 | 서버가 없어 기기를 잃으면 기록도 사라집니다 |
| P0-2 | 러닝 기록 상세 · 헬스+러닝 통합 기록 목록 | 저장은 되는데 다시 열어 볼 방법이 없었습니다 |
| P0-3 | 세트 타입(워밍업 구분) | 워밍업이 볼륨과 개인 기록을 부풀렸습니다 |
| P0-4 | 시간·횟수 기반 운동 | 플랭크·풀업을 중량 운동으로만 기록할 수 있었습니다 |

---

## P1 — 운동 중 조작을 줄이는 것

| 항목 | 내용 |
| --- | --- |
| 러닝 자동 일시정지 | 신호등에서 멈추면 자동으로 멈추고 다시 뛰면 재개. 지금은 손으로 눌러야 해서 페이스가 왜곡됩니다 |
| 러닝 음성 안내 | 1km 마다 거리·시간·페이스를 읽어 줍니다. 화면을 볼 필요가 없어집니다 |
| 원판 계산기 | 목표 중량에 맞춰 봉 양쪽에 끼울 원판을 보여 줍니다. 바벨 앞에서 암산하지 않아도 됩니다 |
| 세트 중 화면 꺼짐 방지 | 설정 항목은 있으나 실제 적용이 남아 있습니다 |

## P2 — 쌓인 기록을 쓸모 있게

| 항목 | 내용 |
| --- | --- |
| 캘린더 | 기록 탭에 월 단위 캘린더. 운동한 날이 한눈에 보입니다 |
| 통계 · 그래프 | 주/월 볼륨, 종목별 1RM 추이, 러닝 거리·페이스 추이 |
| 운동별 전체 이력 | 한 종목의 모든 기록을 한 화면에서 |
| 기록 검색 | 종목·메모로 찾기 |

## P3 — 있으면 좋은 것

| 항목 | 내용 |
| --- | --- |

| 체중 기록 | 지금은 설정값 하나입니다. 날짜별로 남기면 추이를 볼 수 있습니다 |
| 슈퍼세트 | 두 종목을 번갈아 하는 묶음 |
| 루틴 접기/펼치기 · 운동 중 순서 변경 | |
