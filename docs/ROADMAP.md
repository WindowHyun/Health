# 남은 작업

다른 운동 앱(Strong, Hevy, Nike Run Club, Strava, Garmin 등)과 비교해
빠져 있던 것을 모으고, **개인용 앱에 필요 없는 것을 먼저 덜어낸 뒤**
남은 것에 우선순위를 매긴 목록입니다.

기준은 두 가지입니다.

1. **기록을 잃을 수 있는가** — 잃으면 되돌릴 수 없으므로 가장 먼저 합니다.
2. **운동 중 조작을 줄이는가** — 이 앱의 가장 중요한 UX 원칙입니다.

---

## 제외 — 개인 앱에 필요 없음

처음부터 요구사항에서 빠져 있거나, 혼자 쓰는 앱에서는 값을 못 하는 기능입니다.

| 항목 | 이유 |
| --- | --- |
| 로그인 · 회원가입 · 계정 동기화 | 서버를 쓰지 않습니다. 기기 간 이동은 백업 파일로 합니다 |
| 친구 · 팔로우 · 피드 · 클럽 | 혼자 쓰는 앱입니다 |
| 랭킹 · 세그먼트 경쟁 · 챌린지 | 위와 같습니다 |
| 결제 · 구독 · 광고 | 상업용이 아닙니다 |
| 운동 영상 · 자세 가이드 | 유지 비용(영상 제작·저작권)이 개인 앱에 맞지 않습니다 |
| AI 코칭 · 자동 루틴 추천 | 서버나 외부 API 가 필요하고, 넣어 봤지만(v0.5.0) 필요 없어 v0.6.0 에서 뺐습니다 |

## 완료 (v0.4.0)

| 순위 | 항목 | 왜 필요했나 |
| --- | --- | --- |
| P0-1 | 백업 / 복원 · CSV 내보내기 | 서버가 없어 기기를 잃으면 기록도 사라집니다 |
| P0-2 | 러닝 기록 상세 · 헬스+러닝 통합 기록 목록 | 저장은 되는데 다시 열어 볼 방법이 없었습니다 |
| P0-3 | 세트 타입(워밍업 구분) | 워밍업이 볼륨과 개인 기록을 부풀렸습니다 |
| P0-4 | 시간·횟수 기반 운동 | 플랭크·풀업을 중량 운동으로만 기록할 수 있었습니다 |
