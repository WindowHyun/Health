# 시계(Wear OS) 앱

러닝 조작과 휴식 타이머를 손목에서 합니다. **폰 앱이 있어야 동작하는 짝꿍 앱**이라서
폰과 시계에 같은 버전을 모두 설치해야 합니다.

| 하는 일 | 설명 |
| --- | --- |
| 러닝 보기 | 거리 · 시간 · 현재 페이스 · 일시정지/자동 일시정지/신호 끊김 표시 |
| 러닝 조작 | 일시정지 · 계속 · 종료(종료는 한 번 더 확인) |
| 휴식 타이머 | 헬스 중 남은 시간 · −15초 · +15초 · 멈춤/계속 · 건너뛰기 · 끝나면 손목 진동 |

달리기를 **시작**하는 것과 운동 기록(세트 · 무게)은 폰에서 합니다. 시계는 보여 주고 조작만 합니다.

## 요구 사항

* Wear OS 3 이상(갤럭시 워치 4 이상, 픽셀 워치 등). 타이젠 워치(갤럭시 워치 3 이하)는 안 됩니다.
* 폰과 시계가 블루투스로 연결되어 있고 폰에 Google Play 서비스가 있어야 합니다.
* 폰 앱과 시계 앱은 **앱 ID · 서명 키 · 버전이 같아야** 합니다. 한쪽만 업데이트하면 시계가 상태를 못 받을 수 있습니다.

## 설치하기 (Play 스토어를 거치지 않는 방법)

Play 스토어에 올리지 않았으므로 **ADB 로 시계에 직접 설치**합니다(PC 가 필요합니다).
릴리즈(Releases)의 `health-wear-<버전>.apk` 를 받아 둡니다.

### 1. 시계에서 개발자 옵션 켜기

1. 시계 설정 > 시계 정보 > 소프트웨어 정보 > **소프트웨어 버전**을 7번 누릅니다(개발자 모드 켜짐).
2. 설정 > 개발자 옵션에서 **ADB 디버깅**과 **Wi-Fi 디버깅**을 켭니다.
3. 시계가 PC 와 같은 Wi-Fi 에 연결되어 있어야 합니다.

### 2. PC 에서 연결하고 설치하기

```bash
# 시계의 Wi-Fi 디버깅 화면에 나온 IP 와 포트를 씁니다
adb connect 192.168.0.23:5555
adb install -r health-wear-0.10.0.apk
```

* 갤럭시 워치는 "Wi-Fi 디버깅" 화면에서 **새 기기 페어링**(페어링 코드와 포트가 따로 나옴)을
  먼저 해야 할 수 있습니다: `adb pair <IP>:<페어링 포트>` 후 코드 입력, 그다음 `adb connect <IP>:<연결 포트>`.
* `adb` 는 안드로이드 SDK platform-tools 에 들어 있습니다.
* 이미 설치된 상태에서 업데이트할 때도 같은 명령입니다(`-r`). 서명 키가 같아서 기록 · 설정이 남습니다.

PC 가 없다면 폰에서 시계로 APK 를 넣어 주는 "Wear Installer" 같은 앱이 있지만, 이 프로젝트가 확인한 방법은 위의 ADB 입니다.

### 3. 확인

1. 폰의 Health 앱을 한 번 엽니다(처음에 상태를 시계로 올려 보냅니다).
2. 시계 앱 목록에서 **Health** 를 엽니다. "폰에서 운동이나 러닝을 시작하면 여기에 나타나요." 가 보이면 정상입니다.
3. 폰에서 러닝을 시작하면 시계 화면이 러닝 화면으로 바뀝니다. 헬스 세트를 완료해 휴식 타이머가 돌면 휴식 화면이 나옵니다.

## 동작 방식(알아 두면 좋은 것)

* 폰이 러닝 상태와 휴식 타이머를 Wearable Data Layer 로 올립니다. 시계는 경과 시간과 남은 시간을 **스스로 세므로**
  블루투스가 잠깐 끊겨도 숫자가 멈추지 않습니다. 1분 넘게 새 상태가 없으면 "폰과 연결이 끊겼을 수 있어요"라고 알립니다.
* 시계에서 누른 버튼은 폰에 메시지로 갑니다. 폰은 **지금 상태에 맞을 때만** 실행합니다
  (이미 끝난 러닝의 "일시정지" 같은 늦은 입력은 무시).
* 시계가 없어도 폰 앱은 똑같이 동작합니다. 시계로 보내는 일은 실패해도 조용히 넘어갑니다.
* 휴식 타이머가 돌 때는 시계 화면이 꺼지지 않습니다. 러닝 중에는 시스템 설정에 따라 화면이 꺼지고 시계 앱이
  백그라운드로 가므로, 손목을 다시 들고 앱을 열어야 할 수 있습니다. 폰의 러닝 알림은 시계에도 자동으로
  전달되어 거기서 일시정지 · 종료 버튼을 누를 수도 있습니다.

## 알려진 한계

* 시계 앱을 닫아도 러닝은 폰에서 계속 기록되지만, 시계의 "진행 중인 활동" 표시(워치페이스 칩)는 아직 없습니다.
* 시계에 타일 · 컴플리케이션은 없습니다.
* 실제 시계에서의 동작(블루투스 지연, 진동 세기, 화면 꺼짐)은 자동 테스트로 확인할 수 없어서, 처음 쓸 때
  한 번 직접 확인해 주세요.
