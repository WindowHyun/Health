# 헬스 데이터 파일 (종목 · 루틴 템플릿)

기본 운동 종목과 루틴 템플릿은 코드가 아니라 JSON 파일에 있습니다. 두 가지 방법으로 늘릴 수 있습니다.

| 방법 | 언제 | 반영 |
| --- | --- | --- |
| **앱에서 불러오기** | 내 폰에 템플릿을 더하고 싶을 때 | 바로 (앱을 다시 만들 필요 없음) |
| **앱에 포함된 파일 고치기** | 모두에게 기본으로 들어갈 종목 · 템플릿 | 앱을 다시 빌드해야 함 |

---

## 1. 앱에서 불러오기

헬스 탭 > **유명한 루틴 템플릿에서 추가** > 시트 위쪽 버튼.

* **파일에서 불러오기** — 파일 선택기에서 JSON 파일을 고릅니다.
* **붙여넣기** — 복사해 둔 JSON 글을 붙여넣습니다.
* **내 루틴을 파일로 내보내기** — 이 폰의 루틴을 같은 형식의 파일로 저장합니다. 다른 폰에서 불러오거나,
  파일을 고쳐 새 템플릿을 만드는 출발점으로 쓸 수 있습니다. 직접 만든 종목은 파일에 함께 담깁니다.

고르거나 붙여넣으면 **저장하기 전에 먼저 검사**하고 결과를 보여 줍니다.
오류가 하나라도 있으면 아무것도 저장하지 않고, 문제를 모두 알려 줍니다(**문제 목록 복사**로 복사할 수 있습니다).
오류가 없으면 무엇이 들어오는지 보여 주고, **가져오기**를 눌러야 저장합니다.

가져온 템플릿은 목록 맨 위 **가져온 템플릿**에 나타나고, 휴지통 버튼으로 지웁니다
(지워도 이미 만든 루틴은 그대로입니다). 같은 id 의 파일을 다시 가져오면 그 템플릿이 새 내용으로 바뀝니다.
가져온 템플릿은 백업 파일에도 들어가서 복원하면 돌아옵니다.

> 서버에서 내려받는 기능은 없습니다. 파일이나 글로 직접 가져옵니다.

### 검사하는 것

밖에서 온 글이라는 전제로 검사합니다. 같은 규칙을 앱에 포함된 파일에도 씁니다.

| 구분 | 내용 |
| --- | --- |
| **크기** | 파일 256KB 까지. 끝없이 이어지는 파일도 한도에서 읽기를 멈춥니다. 괄호 중첩 8단계까지. |
| **개수** | 종목 100개 · 템플릿 30개(저장은 100개까지) · 템플릿당 하루 14개 · 하루 종목 30개 |
| **글자** | UTF-8 만 받습니다(UTF-16 이나 깨진 글자는 거절). 이름은 앞뒤 공백이 없어야 하고 종목 · 루틴 이름 40자, 제목 60자, 설명 2000자까지. 한글이 풀어 쓴 형태로 들어와도 같은 글자로 맞춥니다. |
| **위험한 문자** | 제어 문자와 글자 방향을 바꾸는 문자(화면의 글을 속일 수 있음)는 거절합니다. 메시지에도 그대로 옮기지 않고 `?` 로 가립니다. |
| **모르는 키** | `reset` 처럼 오타가 난 키는 조용히 넘기지 않고 오류로 알리고 `'rest' 를 쓰려던 건가요?` 라고 제안합니다. |
| **값** | 세트 1~20, 휴식 5~600초. `category` · 요일 같은 정해진 값은 없는 값이면 가능한 값을 알려 줍니다. |
| **종목 이름** | 템플릿이 쓰는 종목은 **이 폰에 있는 종목**이거나 같은 파일의 `exercises` 에 있어야 합니다. 없으면 오류이고 비슷한 이름을 제안합니다(`레그컬` → `'레그 컬' 를 쓰려던 건가요?`). 이름이 틀린 종목이 루틴에서 조용히 빠지는 일을 막기 위해서입니다. |
| **슈퍼셋** | 같은 글자의 `superset` 은 두 종목 이상이 이어서 나와야 합니다. |
| **겹침** | 한 파일 안에서 종목 이름 · 템플릿 id · 루틴 이름이 겹치면 오류입니다. 앱에 포함된 템플릿과 id 가 같아도 오류입니다. |

경고(알림)는 가져오는 것을 막지 않습니다.

* 이미 있는 종목이 파일에 있으면 건너뜁니다(있는 종목은 바꾸지 않습니다).
* 이미 가져온 템플릿과 id 가 같으면 새 내용으로 바꿉니다.
* 다른 템플릿에 같은 이름의 루틴이 있으면, 적용했을 때 같은 이름이 두 개 생긴다고 알려 줍니다.

## 2. 파일 형식

한 파일에 `exercises` 와 `templates` 를 함께 또는 하나만 적을 수 있습니다. `version` 은 적으면 `1` 이어야 합니다.

```json
{
  "version": 1,
  "exercises": [
    { "name": "내 새 운동", "category": "CABLE", "bodyPart": "BACK", "trackingType": "TIME", "defaultRestSeconds": 45 }
  ],
  "templates": [
    {
      "id": "my_split",
      "category": "SPLIT",
      "title": "내 분할",
      "description": "목록에 보이는 설명. 횟수 목표나 대체 운동을 적어 두세요.",
      "days": [
        {
          "name": "하체 (화)",
          "scheduledDays": ["TUESDAY"],
          "exercises": [
            { "name": "스쿼트", "sets": 4, "rest": 120 },
            { "name": "케이블 푸시다운", "sets": 3, "rest": 60, "superset": "A" },
            { "name": "바벨 컬", "sets": 3, "rest": 75, "superset": "A" }
          ]
        }
      ]
    }
  ]
}
```

### 종목 (`exercises`)

| 키 | 값 |
| --- | --- |
| `name` | 종목 이름. 파일 안에서 겹치면 안 됩니다. |
| `category` | `BARBELL` `DUMBBELL` `MACHINE` `CABLE` `BODYWEIGHT` `KETTLEBELL` `CARDIO` `OTHER` |
| `bodyPart` | `CHEST` `BACK` `SHOULDER` `ARM` `LEG` `CORE` `FULL_BODY` `CARDIO` |
| `trackingType` (선택) | `WEIGHT_REPS`(기본, 중량×횟수) `REPS_ONLY`(횟수만) `TIME`(시간만) |
| `defaultRestSeconds` (선택) | 이 종목의 기본 휴식(5~600초). 없으면 앱 설정의 휴식을 씁니다. |

앱에서 가져온 종목은 **직접 만든 종목**이 되어 앱에서 고치거나 지울 수 있습니다.

### 루틴 템플릿 (`templates`)

| 키 | 설명 |
| --- | --- |
| `id` | 템플릿 식별자. 영문자 · 숫자 · `_` · `-` 만, 40자까지. |
| `category` | `BEGINNER` `SPLIT` `STRENGTH` `EQUIPMENT` `FOCUS` (목록 갈래) |
| `title` · `description` | 목록에 보이는 제목과 설명 |
| `days[].name` | 만들어지는 루틴 이름 |
| `days[].scheduledDays` (선택) | `MONDAY` … `SUNDAY`. 있으면 홈의 "오늘의 루틴"에 나옵니다. |
| `exercises[].name` | 종목 이름. **종목의 이름과 정확히 같아야 합니다.** |
| `exercises[].sets` | 기본 세트 수(1~20) |
| `exercises[].rest` (선택) | 휴식(5~600초). 없으면 종목의 기본 휴식, 그것도 없으면 앱 설정의 휴식을 따릅니다. 가능하면 모든 종목에 적어 두세요. |
| `exercises[].superset` (선택) | 같은 글자끼리 슈퍼셋으로 묶입니다. 묶음 종목은 **이어서** 적고, 두 종목 이상이어야 합니다. 묶음은 마지막 종목을 마친 뒤에만 쉽니다. |

앱의 루틴에는 세트 수만 들어갑니다. 횟수 목표 같은 안내는 `description` 에 적습니다.

## 3. 앱에 포함된 파일 고치기

| 파일 | 내용 |
| --- | --- |
| `app/src/main/resources/health/exercises.json` | 기본 운동 종목 |
| `app/src/main/resources/health/routine_templates.json` | 루틴 템플릿 |

위와 같은 형식입니다. 고친 뒤에는 앱을 다시 빌드해야 반영됩니다(파일은 APK 에 함께 들어갑니다).
앱을 업데이트하면 이미 쓰던 기기에도 **빠진 종목만** 더해집니다. 있는 종목은 건드리지 않습니다.

> **이미 있는 종목의 이름을 바꾸거나 지우지 마세요.** 기록과 루틴 템플릿이 이름으로 종목을 가리킵니다.

형식이 틀린 파일은 **앱이 시작할 때 오류**가 되고, 단위 테스트에서 먼저 걸립니다.
오류 메시지에 파일 · 템플릿 id · 날 이름 · 종목 이름이 들어 있어 어디가 틀렸는지 바로 알 수 있고, 문제는 모두 한 번에 알려 줍니다.
파일을 고친 뒤에는 반드시 단위 테스트를 돌리세요.

```
./gradlew :app:testDebugUnitTest
```
